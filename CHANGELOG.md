# Changelog

## 3.5.0 - 2026-09-05

- Rebranded the plugin, metadata, logs, configuration, and permission namespace as Onistone Essentials.
- Added a Bedrock forms GUI for rank sets, permission categories, Allow/Deny/Inherit selection, and per-player overrides.
- Added editable rank display titles, Minecraft colors, brackets, suffixes, weights, and parent ranks.
- Added GUI-based online-player rank assignment and rank creation.
- Preserved the existing command-based administration workflow for console use and automation.
- Added automatic migration for existing plugin data and saved rank/player permissions.
- Fixed `/permissions ... settrue` validation so only the exact action is accepted.

## 3.4.5

- Updated compatibility for Endstone 0.11.9 and Bedrock Dedicated Server 1.26.44.
